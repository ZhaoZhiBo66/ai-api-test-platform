第一次使用，从这里开始

不用先准备外部接口，内置订单链路可以直接回归。

1
启动内置演示运行 scripts/run_demo.py，自动初始化订单服务、测试环境、依赖用例和回归套件。
2
执行核心下单回归平台会完成登录、Token 提取、商品查询、下单、支付和最终状态校验。
3
接入质量门禁quality_gate.py 把断言结果转换为明确退出码，可直接接入 CI。
命令：python scripts/quality_gate.py --suite-name "核心下单回归"

打开文档

一条完整质量链路

所有结果都会被保存，便于复盘、趋势查询和报告生成。

STEP 01

契约导入

从 OpenAPI 建立接口和基础 Schema 用例。

STEP 02

依赖编排

通过变量提取串联登录、下单和支付场景。

STEP 03

套件回归

异步执行业务链，持久化逐条请求和响应。

STEP 04

确定性断言

状态码、JSONPath、Schema 与 SQL 共同判定。

STEP 05

质量门禁

失败返回非零退出码，并保留报告和趋势证据。

平台能力一览

为接口回归质量反馈而设计，而非泛用的 API 调试页。

执行与校验

状态码与 JSONPath 组合断言确定性
被测系统 SQL 数据校验只读
